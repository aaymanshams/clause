# ClauseIQ

**Multi-tenant AI contract intelligence platform** built with Java 21, Spring Boot 3, PostgreSQL + pgvector and LLMs.

ClauseIQ lets organizations upload contracts (PDF/DOCX), extracts key terms with an LLM into a validated schema, flags risky clauses, and answers questions with retrieval-augmented generation (RAG) and source citations, while enforcing strict tenant-level data isolation.

> 🚧 Active development: the full source, tests and documentation are being pushed shortly.

**Stack:** Java 21 · Spring Boot 3 (Web, Security, Data JPA) · JWT · PostgreSQL + pgvector · Flyway · Apache Tika · OpenAI API · JUnit 5 · Mockito · Testcontainers · JaCoCo · Docker
